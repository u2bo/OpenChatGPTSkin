# OpenChatGPTSkin 0.3.1

**发布日期：2026 年 7 月 28 日**

## 版本亮点

### 星宫莓·闪耀舞台正式发布

“星宫莓·闪耀舞台”现已作为第六个 Theme Schema v4 内置主题进入正式发布包。主题提供莓红与粉金舞台配色、动态中英文欢迎语、四个建议卡片图标、项目图标和账户头像，并保持官方项目选择器与输入框的交互几何。README 已改用真实 ChatGPT 应用截图，不再将该主题列为概念。

### 兼容新版 Windows ChatGPT

Windows Runtime 新增原生 AppX 激活路径，通过 `IApplicationActivationManager` 启动受管理的 ChatGPT 窗口；CDP 端口归属与进程父链检查改用 Windows 原生 API。新版 ChatGPT 的根进程现在可以被安全识别，异常循环与不受管理进程仍会被拒绝。

### 更清晰的 Theme Studio 错误反馈

Theme Studio 会保留并展示 Runtime 返回的具体错误，不再把可诊断的启动或应用失败统一替换为模糊的通用英文提示。

### 统一跨平台 Go Host

Windows x64、macOS ARM64 和 macOS x64 继续使用同一套 Go Studio、Controller 与 Runtime 实现。安装包和便携包不捆绑 Node.js，用户无需安装 Git、Go 或开发依赖。

## 已知限制

- Windows Setup 尚未进行商业代码签名，SmartScreen 可能提示未知发布者；只应从项目 GitHub Release 下载并核对 SHA-256。
- macOS 产物尚未使用 Apple Developer ID 签名或公证。首次运行请使用系统标准的 Control-click/右键 → **打开**，不要关闭 Gatekeeper。
- 应用主题前需要完全退出普通 ChatGPT。OpenChatGPTSkin 不会修改官方应用包、账号或 API 配置。
- 官方 ChatGPT 更新可能改变内部 UI 或进程结构；未知结构会被安全拒绝，需要重新适配和验证。
