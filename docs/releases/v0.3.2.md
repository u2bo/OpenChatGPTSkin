# OpenChatGPTSkin 0.3.2

**发布日期：2026 年 7 月 28 日**

## 版本亮点

### 孙悟空·赛亚引擎正式发布

“孙悟空·赛亚引擎”现作为第七个 Theme Schema v4 内置主题进入正式发布包。主题采用深空蓝、电光青与战斗橙配色，包含动态欢迎语、四张建议卡图标、项目图标和账户头像；README 同步展示真实 ChatGPT 桌面应用截图。

### 更准确的人物主题焦点

Theme Studio 首页现在读取主题元数据或内置目录中的缩略图焦点。悟空、星宫莓和三上悠亚主题会将人物主视觉保持在卡片可见区域；悟空在真实 ChatGPT 中使用右侧聚焦，以完整展示人物与拳头。

### 更可靠的恢复校验

Runtime 在主题应用失败后的恢复流程中，会对 ChatGPT 初始界面的短暂提交阶段执行有上限的严格重试。它不会跳过官方外观校验；超时或结构不匹配仍会明确失败，避免误报已恢复。

### 跨平台 Go Host

Windows x64、macOS ARM64 和 macOS x64 继续使用统一的 Go Studio、Controller 与 Runtime 实现。安装包和便携包不捆绑 Node.js，用户无需安装 Git、Go 或开发依赖。

## 已知限制

- Windows Setup 尚未进行商业代码签名，SmartScreen 可能提示未知发布者；仅应从项目 GitHub Release 下载并核对 SHA-256。
- macOS 产物尚未使用 Apple Developer ID 签名或公证。首次运行请使用系统标准的 Control-click/右键 → **打开**，不要关闭 Gatekeeper。
- 应用主题前需完全退出普通 ChatGPT。OpenChatGPTSkin 不会修改官方应用包、账号或 API 配置。
- 官方 ChatGPT 更新可能改变内部 UI 或进程结构；未知结构会被安全拒绝，需要重新适配和验证。
