# OpenChatGPTSkin 0.3.3

**发布日期：2026 年 7 月 29 日**

## 版本亮点

### 原生 Theme CLI

`OpenChatGPTSkin.exe` 及 macOS App 内的原生可执行文件现在直接提供 `theme` 角色。智能体和自动化工具无需 Node.js、npm 或 Go，即可通过机器可读 JSON 调用：

```text
theme help
theme create
theme config
theme show
theme validate
theme pack
theme unpack
```

Windows 便携版或 Setup 安装目录中可直接运行：

```powershell
.\OpenChatGPTSkin.exe theme help
```

### 安全的主题项目工作流

- `create`、`pack` 和 `unpack` 采用只创建语义，拒绝覆盖既有输出；
- `config` 使用 RFC 7396 JSON Merge Patch，在校验通过后原子替换 `theme.json`；
- 完整主题校验统一检查 Schema、声明素材、PNG/JPEG/WebP/WOFF2 文件签名及 `.ocskin` 清单；
- 命令成功只向 stdout 输出一个 JSON 结果；失败只向 stderr 输出包含稳定错误码的 JSON 对象。

### 发布包契约

发布清单升级到 schema v3，并显式声明 `studio`、`controller`、`runtime`、`theme` 四个 Go Host 角色。原生发布构建会执行 `theme help` 烟测；Windows Setup 安装验收也会再次验证该命令。

## 已知限制

- Windows Setup 尚未进行商业代码签名，SmartScreen 可能提示未知发布者；仅应从项目 GitHub Release 下载并核对 SHA-256。
- macOS 产物尚未使用 Apple Developer ID 签名或公证。首次运行请使用系统标准的 Control-click/右键 → **打开**，不要关闭 Gatekeeper。
- 应用主题前需完全退出普通 Codex。OpenChatGPTSkin 不会修改官方应用包、账号或 API 配置。
- 官方 Codex 更新可能改变内部 UI 或进程结构；未知结构会被安全拒绝，需要重新适配和验证。
