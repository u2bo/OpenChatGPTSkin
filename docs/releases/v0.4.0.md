# OpenChatGPTSkin 0.4.0

**发布日期：2026 年 7 月 30 日**

## 版本亮点

### 社区主题目录正式上线

现在可以从 Theme Studio 或项目 README 直接打开 [OpenChatGPTSkin Community](https://u2bo.github.io/OpenChatGPTSkin-Community/zh-CN/themes)，浏览双语介绍、真实首页/任务页截图、兼容状态、版本历史、文件大小和 SHA-256。目前目录已收录全部七个现有主题，并提供导入、投稿和问题举报指南。

### 公开、可复现的主题投稿链路

主题作者可以通过 Pull Request 提交 Theme Schema v4 源目录。可信 CI 会重新校验素材边界、可复现地构建 `.ocskin`、回读归档并发布不可变 Release；同一个 `theme-id + version` 不允许覆盖，内容变化必须提升版本号。

### 可独立使用的 Community Catalog 校验工具

本版本首次在产品 Release 中附带版本一致的 `@open-chatgpt-skin/theme-schema`、`@open-chatgpt-skin/theme-core` 和 `@open-chatgpt-skin/community-catalog` 三个 npm 包，以及记录文件大小和 SHA-256 的 `community-tooling.json`。社区仓库可以固定使用同一套 Schema、归档校验和 Catalog 信任规则，不需要维护第二套验证器。

---

## 新增能力

- **应用内社区入口：** Theme Studio 首页的“更多主题”卡片会按当前语言直接打开社区目录。
- **社区目录契约：** 严格校验双语元数据、版本排序、兼容生命周期、可信媒体/Release URL、截图覆盖和权利声明。
- **Catalog CLI：** 提供 `validate` 与只创建的 `canonicalize` 命令，成功和失败均使用稳定的机器可读 JSON。
- **可信发布产物：** GitHub Release 在原有六个 Windows/macOS 安装与便携产物之外，增加三个社区工具包和 `community-tooling.json`；共享 `checksums.txt` 覆盖全部下载文件。

## 改进

- `.ocskin` ZIP 元数据固定为规范值，相同源目录在不同时间重复打包会生成完全一致的字节。
- README 中的版本、平台、社区目录、投稿、语言和许可证徽章均可点击，并将社区投稿要求提升为主要文档入口。
- 社区工具验收会在干净的外部项目中禁用 lifecycle scripts 后安装三个 tarball，并实际运行 Theme 与 Catalog CLI。

## 平台、兼容性与数据

- 发布平台为 Windows x64、macOS Apple Silicon 和 macOS Intel x64。当前 Windows 官方应用基线为 `OpenAI.Codex 26.721.4979.0`；Codex 更新后仍应按 Runtime 文档重新完成真实视觉和恢复验收。
- 覆盖安装新版 Windows Setup、替换便携目录或替换 macOS `.app` 只更新程序文件，不迁移或覆盖 `%LOCALAPPDATA%\OpenChatGPTSkin` 或 `~/Library/Application Support/OpenChatGPTSkin`。
- Windows 卸载默认保留个人主题、草稿、版本和 Runtime 状态；只有在非静默卸载中明确选择“同时删除个人数据”并确认不可恢复提示时，才会删除用户数据目录。
- Windows Setup 尚未商业签名，可能触发 SmartScreen；macOS 产物尚未使用 Developer ID 签名或公证，属于开发者预览。不要通过关闭 SmartScreen、Gatekeeper 或移除隔离属性来绕过系统保护。

## 已知限制

- 社区网站只负责发现和下载，不会后台安装主题；下载后仍需由用户通过 Theme Studio 手动导入并接受本地 Theme Core 校验。
- 社区权利信息来自投稿者声明，收录不代表项目完成了独立法律核验。发现权利、隐私、安全或兼容问题时请使用社区举报入口。
- Windows Setup 尚未商业签名，macOS 产物尚未使用 Developer ID 签名或公证。仅从项目 GitHub Release 下载并核对 `checksums.txt`。

## 下载

- Windows x64：`OpenChatGPTSkin_0.4.0_windows_x64_Setup.exe` 或 `OpenChatGPTSkin_0.4.0_windows_x64.zip`
- macOS Apple Silicon：`OpenChatGPTSkin_0.4.0_macos_arm64.dmg` 或 `.tar.gz`
- macOS Intel：`OpenChatGPTSkin_0.4.0_macos_x64.dmg` 或 `.tar.gz`
- 社区工具：`open-chatgpt-skin-theme-schema-0.4.0.tgz`、`open-chatgpt-skin-theme-core-0.4.0.tgz`、`open-chatgpt-skin-community-catalog-0.4.0.tgz`
- 所有平台：使用 `checksums.txt` 校验下载文件的 SHA-256

下载目标文件和同一 Release 中的 `checksums.txt` 后，先计算目标文件摘要，再与 `checksums.txt` 中同名条目逐字核对：

```powershell
Get-FileHash .\OpenChatGPTSkin_0.4.0_windows_x64_Setup.exe -Algorithm SHA256
```

```bash
shasum -a 256 OpenChatGPTSkin_0.4.0_macos_arm64.dmg
```

摘要不一致时不要运行或安装文件，应删除下载并通过项目 Issue 报告。
