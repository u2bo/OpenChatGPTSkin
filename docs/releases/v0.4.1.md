# OpenChatGPTSkin 0.4.1

**发布日期：2026 年 7 月 31 日**

`v0.4.1` 是聚焦原生 Theme CLI 的生产化补丁。它不新增或变更社区主题目录、投稿流程或内置主题内容。

## 版本亮点

### 可自描述的 Theme CLI Contract

最终 Windows 和 macOS 构建物新增：

```powershell
.\OpenChatGPTSkin.exe theme contract
```

`theme contract` 向 stdout 输出一个版本化 JSON 文档。当前 Theme CLI Contract 包含 `protocolVersion: 1`、`contractVersion: 1`、`themeSchemaVersion: 4`，以及：

- `create`、`config`、`show`、`validate`、`pack`、`unpack` 的精确命令格式；
- 完整 Theme、Draft 和 `.ocskin` Manifest JSON Schema；
- 图片、字体、主题 JSON、压缩归档和解包内容的大小限制；
- 成功/失败输出流、退出码和稳定错误码；
- 可供其他实现复用的归档有效/无效用例。

自动化不再需要解析 `help` 文本或猜测字段。成功时 stdout 只有一个 JSON 值且 stderr 为空；失败时 stderr 只有一个结构化错误。退出码 `0`、`1`、`2` 分别表示成功、命令失败和参数用法错误。

### 最终构建物完整验收

发布验收现在直接调用最终原生可执行文件，真实执行：

```text
contract → create → config → show → validate → pack → unpack → validate
```

该流程会创建测试背景图和 Merge Patch，确认 `show` 能观察到修改，校验源主题，打包 `.ocskin`，解包到新目录并再次校验。Windows x64 Stage、Windows Setup 实际安装后的 `OpenChatGPTSkin.exe`、macOS ARM64 App 和 macOS x64 App 共用同一验收逻辑。最终用户机器不需要 Node.js、npm、Go 或 Git。

## 平台、兼容性与数据

- 发布目标：Windows x64、macOS Apple Silicon 和 macOS Intel x64。
- Windows Setup 默认安装到 `%LOCALAPPDATA%\Programs\OpenChatGPTSkin`；个人数据继续保存在 `%LOCALAPPDATA%\OpenChatGPTSkin`，覆盖安装不会迁移或覆盖它。
- 当前 Windows 官方应用兼容基线仍为 `OpenAI.Codex 26.721.4979.0`。Codex 更新后应重新执行 Runtime 真实设备验收。
- Windows Setup 尚未商业签名，可能触发 SmartScreen；macOS 产物尚未 Developer ID 签名或公证。不要关闭系统安全功能来绕过提示。
- Theme CLI 只处理用户明确传入的本地路径，不会修改 `WindowsApps`、`Codex.app`、`app.asar`、账号、API 配置、项目文件或聊天内容。

## 下载

- Windows x64：`OpenChatGPTSkin_0.4.1_windows_x64_Setup.exe` 或 `OpenChatGPTSkin_0.4.1_windows_x64.zip`
- macOS Apple Silicon：`OpenChatGPTSkin_0.4.1_macos_arm64.dmg` 或 `OpenChatGPTSkin_0.4.1_macos_arm64.tar.gz`
- macOS Intel：`OpenChatGPTSkin_0.4.1_macos_x64.dmg` 或 `OpenChatGPTSkin_0.4.1_macos_x64.tar.gz`
- 所有平台：使用同一 Release 中的 `checksums.txt` 校验 SHA-256

Windows PowerShell：

```powershell
Get-FileHash .\OpenChatGPTSkin_0.4.1_windows_x64_Setup.exe -Algorithm SHA256
```

macOS Terminal：

```bash
shasum -a 256 OpenChatGPTSkin_0.4.1_macos_arm64.dmg
```

摘要必须与 `checksums.txt` 中同名条目完全一致；不一致时不要运行或安装文件。

## 已知限制

- macOS 仍是未签名开发者预览，真实 Codex 视觉闭环需要按架构持续复验。
- `protocolVersion` 或 `contractVersion` 未被调用方识别时，调用方应停止写入并升级适配，而不是猜测兼容行为。
- Theme CLI 不下载、生成或上传素材，也不会自动发布主题；素材授权和再分发权仍由调用者确认。
