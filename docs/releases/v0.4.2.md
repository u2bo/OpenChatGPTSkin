# OpenChatGPTSkin 0.4.2

**发布日期：2026 年 8 月 9 日**

`v0.4.2` 新增第八个内置主题 **Tibo·赛博智核**，并将同一份经过校验的主题作为 `tibo-cyber-core` `1.0.0` 发布到 OpenChatGPTSkin Community。现有主题、Theme Schema v4、Runtime 安全边界和 `v0.4.1` 引入的原生 Theme CLI Contract 保持兼容。

## 版本亮点

### Tibo·赛博智核成为内置主题

新主题以近黑代码舱、青蓝霓虹和右侧 Tibo 人物为核心，在左侧保留低干扰工作区，并为首页和任务工作区提供一致的视觉表现：

- 中英文动态欢迎语和项目名插值；
- 半透明深色面板、青色边框和代码字体；
- 代码、立方体、盾牌和火箭四组建议卡片图标；
- 项目图标、账户头像及任务工作区背景投影。

Windows x64、macOS ARM64 与 macOS x64 发布产物现在都包含八个内置主题。主题可以通过 Theme Studio 预览和应用，也可以通过原生 Theme CLI 查询和校验。

### 社区目录同步发布

[Tibo·赛博智核社区详情页](https://u2bo.github.io/OpenChatGPTSkin-Community/zh-CN/themes/tibo-cyber-core) 提供双语说明、真实首页与任务截图、兼容状态、逐文件权利声明、文件大小和 SHA-256。`.ocskin` 从社区仓库的不可变 GitHub Release 下载；同一个 `theme-id + version` 不会被覆盖。

### README 直接展示实际效果

双语 README 已增加 Tibo 主题介绍、实际首页效果图和社区下载入口。主题数量、Runtime 文档、Theme Studio 文档和验收基线同步更新为八个。

## 下载

- Windows x64：`OpenChatGPTSkin_0.4.2_windows_x64_Setup.exe` 或 `OpenChatGPTSkin_0.4.2_windows_x64.zip`
- macOS Apple Silicon：`OpenChatGPTSkin_0.4.2_macos_arm64.dmg` 或 `OpenChatGPTSkin_0.4.2_macos_arm64.tar.gz`
- macOS Intel：`OpenChatGPTSkin_0.4.2_macos_x64.dmg` 或 `OpenChatGPTSkin_0.4.2_macos_x64.tar.gz`
- 所有平台：使用同一 Release 中的 `checksums.txt` 校验 SHA-256

Windows PowerShell：

```powershell
Get-FileHash .\OpenChatGPTSkin_0.4.2_windows_x64_Setup.exe -Algorithm SHA256
```

macOS Terminal：

```bash
shasum -a 256 OpenChatGPTSkin_0.4.2_macos_arm64.dmg
```

摘要必须与 `checksums.txt` 中同名条目完全一致；不一致时不要运行或安装文件。
